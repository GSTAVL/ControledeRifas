# Configuração do SharePoint

## Pré-requisitos

- acesso a um site SharePoint;
- permissão para criar listas;
- permissão para criar conexões no Power Apps.

## Passos

1. Criar uma lista chamada Materiais.
2. Renomear a coluna Title para Material, se desejado.
3. Criar a coluna Quantidade como Número.
4. Criar a coluna Valor como Moeda.
5. Criar a coluna Status como Escolha.
6. Adicionar as opções Comprado e Não Comprado.
7. Criar a coluna Condição como Escolha.
8. Adicionar as opções utilizadas pelo aplicativo.
9. Abrir o Canvas App.
10. Criar ou atualizar a conexão com a lista.
11. Confirmar que o nome da fonte de dados é MateriaisLista.

## Teste da conexão

1. Criar um registro pelo formulário.
2. Abrir a lista no SharePoint.
3. Confirmar que o registro foi criado.
4. Alterar o registro pelo aplicativo.
5. Confirmar que o item existente foi atualizado.
