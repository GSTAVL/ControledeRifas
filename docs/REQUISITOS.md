# Requisitos do projeto

## Requisitos funcionais da AC1

### RF01: listar materiais

O sistema deve apresentar os materiais cadastrados na lista do SharePoint.

### RF02: cadastrar material

O sistema deve permitir o cadastro de um material com nome, quantidade e valor.

### RF03: validar campos

O sistema deve impedir o salvamento quando os campos obrigatórios não estiverem preenchidos.

### RF04: pesquisar material

O sistema deve permitir a pesquisa de materiais pelo nome.

### RF05: editar material

O sistema deve permitir a seleção e edição de um material existente.

### RF06: persistir informações

O sistema deve gravar as inclusões e alterações na lista do SharePoint.

### RF07: apresentar confirmação

O sistema deve informar se o material foi cadastrado ou atualizado com sucesso.

## Requisitos não funcionais

### RNF01: usabilidade

A interface deve apresentar navegação clara entre as telas.

### RNF02: identidade visual

O aplicativo deve utilizar uma identidade visual consistente.

### RNF03: persistência

Os registros devem permanecer disponíveis após o encerramento do aplicativo.

### RNF04: controle de acesso

O acesso à lista depende das permissões configuradas no ambiente Microsoft 365.
